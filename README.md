Lithora — AI-Powered Kidney Stone Detection

Lithora is a web-based research prototype that analyzes kidney CT scan images using computer vision and a trained deep learning model.


About the Project
Lithora explores how machine learning and image processing can support preliminary analysis of kidney CT images. Users can upload a scan through a simple web interface and view the model's prediction.

Features
Upload kidney CT images through a web interface
Process images using OpenCV
Generate predictions using a trained TensorFlow/Keras model
Display results and the model's output score
Simple, responsive interface built with HTML and CSS
